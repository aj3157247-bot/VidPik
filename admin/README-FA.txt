سایت مستقل پنل مدیریت VidPik

این پروژه جدا از سایت عمومی است و هیچ فایل رابط کاربری به سایت VidPik اضافه نمی‌کند.
آدرس پیشنهادی پس از انتشار: https://vidpik-admin.pages.dev

۱) پوشه 02-SEPARATE-ADMIN-WEBSITE را به‌عنوان یک پروژه مستقل Cloudflare Pages منتشر کن. Build command خالی و Build output directory همان ریشه پروژه باشد.
۲) در تنظیمات پروژه اصلی VidPik، مقدار VIDPIK_ADMIN_ORIGIN را به‌صورت Variable برابر https://vidpik-admin.pages.dev اضافه کن.
۳) در پروژه اصلی، Secretهای VIDPIK_ADMIN_PASSWORD و VIDPIK_ADMIN_SECRET را تنظیم کن. برای Secret دوم یک رشته تصادفی طولانی حداقل ۳۲ کاراکتری بساز.
۴) دیتابیس D1 را طبق schema.sql بساز و در پروژه اصلی با نام Binding برابر DB وصل کن.
۵) پوشه 01-MAIN-SITE-INTEGRATION را روی نسخه اصلی VidPik اعمال کن: _worker.js و index.html جایگزین شوند و schema.sql در D1 اجرا شود. admin.html قبلی سایت اصلی عمداً دست‌نخورده می‌ماند.
۶) پس از Deploy سایت اصلی، پنل مستقل را باز کن و با رمز مدیر وارد شو.

توجه: آمار از زمان فعال‌سازی شروع می‌شود و آمار قبلی موجود نیست. تعداد دانلودها درخواست دانلود را نشان می‌دهد، نه تضمین تکمیل فایل. تنظیمات تبلیغات در پنل ذخیره می‌شود؛ نمایش تبلیغ در رابط عمومی هنوز به اتصال جایگاه‌های نمایش نیاز دارد.
