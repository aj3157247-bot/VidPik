# VidPik — دانلود لینک‌های مستقیم ویدیوهای عمومی آپارات

سایت فارسی راست‌چین برای بررسی لینک ویدیوهای عمومی آپارات و نمایش لینک‌های دانلودی که API آپارات در دسترس قرار می‌دهد.

## محتویات
- `index.html` — رابط کاربری کامل و واکنش‌گرا با برند VidPik
- `favicon.svg` — آیکون سایت
- `functions/api/resolve.js` — Pages Function برای بررسی ویدیو و استخراج لینک‌های مستقیم قابل‌دسترسی
- `functions/api/health.js` — بررسی فعال‌بودن API

## نصب در GitHub و Cloudflare Pages (روش پیشنهادی)

این نسخه از **Pages Functions استاندارد** استفاده می‌کند؛ پس برایش `_worker.js` لازم نیست.

1. ZIP را استخراج کن.
2. همه فایل‌ها و پوشه‌ها را در ریشه مخزن GitHub قرار بده. ساختار باید دقیقاً این‌طور باشد:
   - `index.html`
   - `favicon.svg`
   - `functions/api/resolve.js`
   - `functions/api/health.js`
3. در Cloudflare برو به **Workers & Pages → Create application → Pages → Connect to Git** و مخزن را انتخاب کن.
4. اگر پروژه فقط همین فایل‌های استاتیک را دارد، تنظیمات Build را طوری بگذار که `index.html` و پوشه `functions` در خروجی نهایی باشند. برای استقرار بدون مرحله build معمولاً Build command را خالی بگذار و ریشه خروجی را `.` انتخاب کن، اگر تنظیمات پروژه این حالت را پشتیبانی می‌کند.
5. Deploy کن.
6. آدرس `https://YOUR-SITE.pages.dev/api/health` را باز کن. پاسخ موفق باید شامل `"ok":true` و `"service":"VidPik"` باشد.
7. صفحه اصلی را باز کن و یک لینک ویدیوی عمومی آپارات را آزمایش کن.

### اگر مخزن فعلی سایتت Advanced Mode دارد
اگر پروژه فعلی از `_worker.js` استفاده می‌کند، Pages Functions استاندارد به‌صورت هم‌زمان با Advanced Mode اجرا نمی‌شود. در این حالت یا پروژه را به روش استاندارد Pages Functions تبدیل کن، یا منطق این دو endpoint را با Worker فعلی ادغام کن. قبل از جایگزین‌کردن فایل‌های یک سایت موجود، نسخه پشتیبان بگیر.

## روش استفاده
1. لینک کامل یک ویدیوی عمومی با قالبی مانند `https://www.aparat.com/v/VIDEO_ID` را وارد کن.
2. «بررسی لینک» را بزن.
3. اگر API آپارات لینک‌های فایل مستقیم را برگرداند، کیفیت موجود نمایش داده می‌شود.
4. روی کیفیت کلیک کن؛ لینک رسانه در برگه جدید باز می‌شود. در صورت نیاز، از منوی مرورگر دانلود/ذخیره را انتخاب کن.

## محدودیت‌های واقعی
- این پروژه در این محیط روی Cloudflare مستقر نشده و دانلود زنده از یک نمونه ویدیو از اینجا تأیید نشده است. بنابراین پیش از استفاده عمومی باید با لینک واقعی آزمایش شود.
- endpoint و فیلدهای API استفاده‌شده در این پروژه، API عمومی تضمین‌شده برای توسعه‌دهندگان نیستند و ممکن است بدون اطلاع تغییر کنند.
- عمومی‌بودن صفحه ویدیو به معنی وجود لینک دانلود مستقیم نیست. اگر API لینک فایل را برنگرداند یا `can_download` غیرفعال باشد، این ابزار محدودیت را دور نمی‌زند.
- فایل ویدیو از سرور تو عبور داده نمی‌شود؛ مرورگر مستقیماً به لینک رسانه برمی‌ود. این روش از نیاز به ذخیره ویدیو و انتقال فایل حجیم از Worker جلوگیری می‌کند.
- بعضی لینک‌ها ممکن است امضای زمان‌دار داشته باشند؛ اگر منقضی شد، دوباره لینک ویدیو را بررسی کن.
- فقط محتوایی را دانلود کن که مجوز ذخیره آن را داری.

## عیب‌یابی
- **`/api/health` خطای 404 می‌دهد:** پوشه `functions` ممکن است در خروجی انتشار نباشد، یا سایت در حالت Advanced Mode اجرا شود.
- **لینک مستقیم پیدا نشد:** احتمال دارد دانلود مستقیم برای آن ویدیو ارائه نشده باشد یا API تغییر کرده باشد.
- **صفحه اصلی 404 می‌دهد:** مطمئن شو `index.html` در ریشه خروجی انتشار قرار دارد.
- **خطای API:** ابتدا `/api/health` را بررسی کن، سپس پیام خطای نمایش‌داده‌شده را بخوان.
