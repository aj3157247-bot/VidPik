ارتقای VidPik Admin Pro
========================

این نسخه بر اساس VidPik-main (8).zip ساخته شده و اصلاح CORS فایل Worker.js قبلی نیز در آن ادغام شده است.

چه چیزهایی تغییر کرده؟
- پنل مدیریت تبلیغات بازطراحی شده و برای هر جایگاه عنوان، متن، لینک مقصد قابل کلیک، آدرس تصویر/بنر، متن دکمه و تاریخ شروع/پایان دارد.
- پیش‌نمایش هر تبلیغ در همان پنل نمایش داده می‌شود.
- تبلیغات فعال و در بازه زمانی معتبر از API عمومی /api/ads خوانده می‌شوند.
- سایت اصلی تبلیغات صفحه اصلی، پیش از دانلود و زیر پلیر را نمایش می‌دهد؛ لینک تبلیغ در تب جدید باز می‌شود.
- کلیک روی تبلیغ به‌عنوان رویداد ad_click ثبت می‌شود.
- اصلاح CORS برای /api/health حفظ شده است.
- سایر قابلیت‌های قبلی پروژه نگه داشته شده‌اند.

نحوه انتشار:
1) محتوای پوشه VidPik-main را در ریشه همان مخزن GitHub پروژه اصلی جایگزین/به‌روزرسانی کن؛ فایل‌های موجود دیگر را حذف نکن.
2) پروژه اصلی Cloudflare Pages با Root directory خالی و Build output directory متناسب با تنظیم فعلی پروژه، دوباره Deploy شود.
3) پروژه vidpik-admin همچنان باید از همان مخزن با Root directory برابر admin منتشر شود. اگر اتصال GitHub خودکار است، با ثبت تغییرات، هر دو پروژه Deploy می‌شوند.
4) در پروژه اصلی، Secretهای VIDPIK_ADMIN_PASSWORD و VIDPIK_ADMIN_SECRET و Variable به نام VIDPIK_ADMIN_ORIGIN با مقدار https://vidpik-admin.pages.dev باید باقی بمانند.
5) Binding دیتابیس D1 با نام DB در پروژه اصلی باید باقی بماند. جدول site_settings باید طبق schema.sql ساخته شده باشد.
6) در پنل مدیریت > تنظیمات تبلیغات، برای هر جایگاه لینک مقصد وارد کن، آن را فعال کن و «ذخیره و انتشار تبلیغات» را بزن.

نکته:
- لینک مقصد و تصویر باید آدرس کامل http:// یا https:// باشند.
- تا وقتی لینک مقصد ثبت نشده باشد، تبلیغ در سایت عمومی نمایش داده نمی‌شود.
- تاریخ شروع و پایان اختیاری است.
- مقادیر رمز و کلید محرمانه را در GitHub یا در اختیار دیگران قرار نده.
