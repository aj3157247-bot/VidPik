VidPik — نقشه سایت و تنظیمات ایندکس گوگل

در این نسخه:
- GET /sitemap.xml از داخل Cloudflare Pages Advanced Mode Worker تولید می‌شود.
- GET /robots.txt موتورهای جست‌وجو را به Sitemap هدایت می‌کند.
- فقط صفحه اصلی در Sitemap قرار دارد؛ چون نسخه فعلی برنامه صفحه دائمی و مستقل برای هر ویدیو ندارد.
- مسیرهای /api/ عمداً در robots.txt بسته شده‌اند؛ پاسخ‌های API صفحات محتوایی قابل ایندکس نیستند.
- صفحه اصلی دارای canonical ثابت https://vidpik.pages.dev/ است.

آزمایش پس از Deploy:
1) https://vidpik.pages.dev/sitemap.xml را باز کن؛ باید XML معتبر با یک URL صفحه اصلی ببینی.
2) https://vidpik.pages.dev/robots.txt را باز کن؛ باید خط Sitemap را ببینی.
3) در Google Search Console بخش Sitemaps، فقط sitemap.xml را ثبت کن.

نکته:
lastmod ساختگی اضافه نشده است. تاریخ lastmod فقط وقتی باید درج شود که زمان واقعی آخرین تغییر محتوای صفحه در دسترس باشد.
Video Sitemap هم فعلاً ساخته نشده، چون برنامه در این نسخه URL اختصاصی و دائمی برای صفحات ویدیو ندارد.
برای اضافه‌کردن ویدیوها در آینده، ابتدا باید صفحات مستقل با URL پایدار، عنوان، تصویر بندانگشتی ویدیو و محتوای قابل مشاهده ایجاد شوند.
