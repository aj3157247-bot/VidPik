VidPik — فایل‌های لازم برای تغییرات

فایل‌های این بسته را در ریشهٔ پروژه جایگزین کن: index.html، _worker.js، manifest.webmanifest. admin.html از قبل در پروژه وجود دارد و مسیرهای API آن اکنون در _worker.js پیاده‌سازی شده‌اند.

تنظیمات Cloudflare Pages:
1) Settings → Variables and Secrets: متغیر VIDPIK_ADMIN_PASSWORD را با رمز قوی تنظیم کن.
2) متغیر VIDPIK_ADMIN_SECRET را با رشتهٔ تصادفی طولانی (حداقل 32 کاراکتر) تنظیم کن.
3) Settings → Bindings: یک KV Namespace به نام دقیق VIDPIK_KV وصل کن تا آمار و تبلیغات ذخیره شوند.
4) پس از Deploy، پنل مدیریت از /admin.html در دسترس است.

یادآوری: جست‌وجو از API عمومی آپارات استفاده می‌کند و اگر آپارات مسیر یا دسترسی را تغییر دهد، جست‌وجو ممکن است موقتاً خطا دهد. لینک مستقیم فعلی همچنان در دسترس است. این تغییرات جایگزین فایل‌های اصلی می‌شوند؛ از نسخهٔ فعلی نسخهٔ پشتیبان نگه دار.
