VidPik — تنظیم جست‌وجوی گستردهٔ گوگل

این بسته فقط فایل‌های تغییرکرده را دارد: index.html و _worker.js.

برای فعال‌شدن جست‌وجوی واقعی، باید کلید API را در Cloudflare تنظیم کنی؛ بدون کلید هیچ سایت نمی‌تواند درخواست‌های جست‌وجوی حساب‌دار را از طرف تو اجرا کند.

روش پیشنهادی (Google results از طریق SerpApi):
1) در serpapi.com حساب بساز و یک API key بگیر. ممکن است ثبت‌نام یا استفاده هزینه/محدودیت داشته باشد.
2) Cloudflare Dashboard → Workers & Pages → پروژهٔ VidPik → Settings → Variables and Secrets.
3) یک Secret با نام دقیق SERPAPI_KEY بساز و مقدار API key را وارد کن.
4) Save کن و Deploy جدید انجام بده.
5) در سایت جست‌وجو کن؛ نتایج صفحه‌بندی شده‌اند و دکمهٔ «نتایج بیشتر» تا 10 نتیجه در هر درخواست می‌آورد.

راه جایگزین برای حساب‌هایی که از قبل Google Programmable Search JSON API دارند:
- Secrets: GOOGLE_API_KEY و GOOGLE_CSE_ID را تنظیم کن.
- API گوگل برای حساب‌های جدید ممکن است قابل فعال‌سازی نباشد؛ در این صورت از روش SerpApi استفاده کن.

محدودیت مهم دانلود:
جست‌وجو نتیجه‌های وب را از سایت‌های مختلف نشان می‌دهد. نتیجهٔ غیرآپارات با دکمهٔ «بازکردن ویدیو» به سایت اصلی می‌رود. دانلود مستقیم از هر وب‌سایتی با یک مسیر عمومی تضمین‌پذیر نیست؛ هر سرویس سازوکار، محدودیت و مجوز خودش را دارد. مسیر دانلود/استخراج فعلی VidPik برای آپارات است و برای پشتیبانی دانلود از سایت دیگر باید آن سایت جداگانه پیاده‌سازی و آزمایش شود. لینک‌های مستقیم فایل ویدیو نیز فقط وقتی قابل دانلودند که خود منبع دسترسی بدهد.
